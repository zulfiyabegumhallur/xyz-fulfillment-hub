# AI Usage Note

I used AI to help structure the fulfillment workflow, generate sample operational data, and create the first version of the interface.

I kept the solution focused on the main operational problems in the assignment rather than trying to build a complex enterprise system.

I changed/validated AI suggestions in two areas:
1. I kept the navigation intentionally simple because the warehouse team is described as experienced but not very comfortable with technology.
2. I prioritized order visibility, priority handling, inventory availability, staging/shipping, and issue tracking because these directly map to the problems described in the brief.

All business and operational data in the prototype is dummy data created for demonstration.
