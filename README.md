# XYZ Fulfillment Hub — Take-Home Project

## What this solves
The assignment describes a spreadsheet/shared-folder fulfillment process with poor order visibility, missed priority deadlines, missing stock, wrong variants, misplaced packed boxes, missed courier pickups, and informal issue handling.

This prototype focuses on:
1. A single order dashboard and status pipeline.
2. A visible priority queue.
3. Inventory visibility across Main and Backup warehouses.
4. Shipping/staging visibility with courier pickup windows.
5. An issue log so operational problems are assigned and not forgotten.

## How to run
No installation is required.

1. Open `index.html` in Chrome/Edge.
2. Use the left navigation to move between Dashboard, Orders, Inventory, Shipping, and Issues.
3. Use the sample data to demonstrate the workflow.
4. Click Update/Process on an order to move it through the sample fulfillment stages.

## Sample data
All data is dummy data created for the assignment. No real store or courier integrations are used.

## Design decisions
The warehouse team is described as experienced but not very comfortable with technology, so the interface uses large labels, a small number of navigation options, clear status badges, and simple actions.
