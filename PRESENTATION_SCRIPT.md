5-MINUTE PRESENTATION SCRIPT

Hello, this is my solution for the XYZ Fulfillment Hub take-home project.

I first understood the existing process: orders are received, processed, picked, packed, staged and then handed to a courier. The current process depends heavily on spreadsheets and shared folders.

The main problems I focused on were lack of order visibility, priority orders getting mixed with regular orders, stock not being available where expected, packed boxes being misplaced, missed courier pickups, and issues being handled informally.

I built a simple Fulfillment Hub with five areas.

First is the Dashboard. It gives the office and warehouse teams one quick view of today's orders, priority orders, orders waiting for packing and open issues. I also added a priority queue so urgent orders are visible immediately.

Second is Orders. Each order has a clear status: Received, Picking, Packing, Staged or Blocked. The Process button demonstrates how an order moves through the workflow.

Third is Inventory. XYZ has a main and nearby backup warehouse. The application shows both quantities and highlights when the main warehouse has no stock but the backup warehouse does. This can create a transfer task before the picker starts searching for the product.

Fourth is Shipping and Staging. The team can see the courier, pickup window, box location and whether the shipment is ready or has a pickup problem.

Finally, there is an Issues section. Instead of solving problems informally and forgetting them, each issue is visible with the order, problem type, detail, owner and current status.

I deliberately kept the interface simple because the brief says the warehouse team is experienced but not very comfortable with technology.

The application uses only sample data because the assignment does not provide real store or courier systems. The goal is to demonstrate a practical workflow rather than pretend to have real integrations.

Overall, the solution creates a single operational view from order receipt through courier handover, while making priority work, stock problems and exceptions easier to see and act on.
